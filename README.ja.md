# Surimono（摺物）

[![DMG のダウンロード数](https://img.shields.io/endpoint?url=https%3A%2F%2Fraw.githubusercontent.com%2Fphyten%2Fsurimono%2Fstats%2Fdownloads-dmg.json)](https://github.com/phyten/surimono/releases) [![ZIP のダウンロード数](https://img.shields.io/endpoint?url=https%3A%2F%2Fraw.githubusercontent.com%2Fphyten%2Fsurimono%2Fstats%2Fdownloads-zip.json)](https://github.com/phyten/surimono/releases)

> 雑に開いて、雑に見て、さっと刷る。

**Surimono** は、Markdown・PDF・画像・Org・テキスト・HTML・LaTeX といった身近な書類や画像を、すぐに見て、そのまま気軽に印刷するための macOS アプリです。印刷を主役に据えていて、**108 のスタイル**の差し替え、HTML のノイズ除去プリセット、中綴じ冊子印刷（A3 に A4 を 2 ページ並べて両面印刷し、中央で折って綴じる）に対応します。

**108 のスタイルで刷れます。** 手紙や報告書から、錦絵の見出し、運動会のプログラムまで、自分の文書の 1 ページ目の見本を見ながら選べます。

名前は江戸時代の私家版木版画「摺物」と、「摺る＝刷る」に由来します。

[English README](README.md)

> [!NOTE]
> Surimono は開発初期の段階です。

## なぜ作るのか

Mac で Markdown のメモや Org ファイル、長い HTML の記事を印刷しようとすると、ブラウザやエディタのプラグイン、PDF ツールを経由する遠回りになりがちです。Surimono は「開いて、印刷を押す」の 2 手で済むことを目指します。

## 機能

- ⌘N でクリップボードの Markdown・テキスト・HTML ソース・画像を、元のファイルを保存せずそのまま開く
- どのアプリでも、選んだ文字をサービスのメニュー（Surimono で開く・Surimono で刷る）から開いて刷れる。「ファイルとして保存…」を選ぶまでメモリの上だけに置く
- Markdown の親ファイルを合本で開ける: `<<[file]`（Marked）・`{{file}}`（MultiMarkdown）・`/file`（iA Writer）と、リンクだけの SUMMARY.md を読み、親の本文を前書きにして並べる
- [Marked と互換](https://markedapp.com/help/Streaming_Preview)のストリーミングプレビュー: `mkStreamingPreview` ペーストボードへ書くアプリの文字を、ファイルを作らずその場で見せる（相対パスの画像の基準 URL は使わない）
- Markdown・Org のコードをシンタックスハイライトし、Markdown の囲み（`:::` と `> [!note]`）を札・アイコン・線の種類で分けて表示（白黒で刷っても種類が分かる）。JavaScript を使わずオフラインで処理
- Markdown の拡張記法: 脚注、`==ハイライト==`、`^上付き^`・`~下付き~`、ルビ `{漢字|かんじ}`、絵文字 `:tada:`、定義リスト、見出しの ID と目次 `[TOC]`
- Markdown の ```` ```mermaid ```` と Org の `#+begin_src mermaid` を、オフラインで SVG の図にして印刷。描けない図は原文を残し、印刷前の確認に表示します。
- Markdown の数式（`$…$`・`$$…$$`・```` ```math ````）を、純 Swift の KaTeX 互換の組版（[SwaTex](https://github.com/PhraseHQ/SwaTex)）で JavaScript なしに描画。化学式（mhchem）も
- Markdown・PDF・画像・Org・テキスト・HTML・CSV・LaTeX のクイックビューア
- LaTeX の文書をスタイルで刷る: 表題、番号つきの節と参照、リスト（enumitem）、コード（listings）、SwaTex による数式と式番号、脚注、hyperref、xcolor、図（graphicx）、表（booktabs）、定理と証明（amsthm）、参考文献と引用、単位（siunitx）。TeX を動かすのではなく、よく使う部分集合を読む。TikZ の図は場所を枠で示す
- Markdown・Org・テキスト・CSV・LaTeX・HTML・PDF・画像を「合本」にまとめ、開いている窓へのドロップや「文書を足す…」で足し、並べ替え・取り除きの後、1 つの PDF や冊子として出力（各文書を奇数ページから始める設定付き）。閉じた合本は「ファイル > 最近使った合本」から開き直せる
- 種類が混ざった複数の画像を、1 つの「画像の束」としてまとめて開く
- サムネイルのドラッグや ⌥⌘↑ / ⌥⌘↓ で画像を並び替え
- 画像の束を現在の並び順と印刷レイアウトで PDF に書き出し
- 出てくる用紙の単位で表と裏を並べる印刷画面。冊子は折り線つきで並べ、「折った仕上がりを見る」で折った冊子をめくって確かめられる。ピンチ・⌘＋スクロール・ダブルクリック・⌘＋／⌘−で、指の位置を中心に実物の 2 倍まで拡大し、収まらない用紙はドラッグで動かせる（刷る大きさは変わらない）
- Markdown・Org・テキスト・CSV・LaTeX 向けの印刷用スタイルシート 108 種を、12 のカテゴリー（日常・和の趣・ビジネス・学術・技術・読みもの・ノート・印刷向け・レトロ・ポップ・季節・子ども）で切り替え。文書の 1 ページ目の見本を並べたパレットから選び（上に「最近使った」「お気に入り」「定番」）、表示画面では乗せると紙で試せる。4 つまで並べて、同じ見出しやコードから見比べることもできる。自作 CSS も追加可能。「LaTeX 風」は欧文を Computer Modern（同梱の KaTeX の書体）で組み、LaTeX と同じく節に番号を振って段落を字下げする。遊びのあるスタイルは絵文字を散らし、同じ文書なら画面と印刷で同じ絵柄
- 表示画面と印刷画面のどちらからも、スタイルの見本を並べたパレットを開けます。「この文書」と、見出し・表・コードなどを含む「見本の文書」を切り替えられ、選択はアプリ全体で覚えます。見本の文書は日本語・英語を同梱しています。検索と1つのスクロールする一覧に、最近使った・お気に入り・定番・カテゴリー・自分のスタイルを並べます。表示画面では乗せると紙で試せ、印刷画面では右側の見本だけを拡大し、クリックで決めてから用紙を組み直します。Esc または外側のクリックで閉じます。印刷画面の初回だけ、スタイルのボタンに短い案内を出します
- Markdown・Org・テキスト・CSV・LaTeX の文字の大きさを、スタイルに重ねて80〜200%で変更。窓と用紙の大きさを保ち、印刷・PDF 書き出しにも反映
- コードの配色: スタイルとは別に 12 の配色を選べ、枠・行番号・長い行の扱い・言語名の表示も変えられる
- HTML のノイズ除去プリセット（ナビゲーション、広告、サイドバー、Cookie バナーなど。追加・編集可能）
- HTML のスマート削除（ベータ）: 広告・おすすめ記事・SNS ボタン・Cookie バナーなどを自動で見つけて消し、消した部分を確かめて 1 つずつ残せる（判定はこの Mac の中だけ）
- 印刷前の確認: 読めない画像・幅の広すぎるブロック・数式のエラー・未対応の LaTeX を、ページと直し方付きで表示。問題がない文書では操作を増やさず、印刷も止めません。
- 印刷レイアウト: A4・B5・Letter の片面 / 両面、A4 冊子・A5 冊子、B5 冊子・B6 冊子、Letter 冊子・Half Letter 冊子（それぞれ倍の大きさの用紙に両面印刷）。冊子は「印刷の設定」で左とじ / 右とじを選べます。
- 「2 ページを 1 枚に」は A3 / A4・B4 / B5・Tabloid / Letter、「4 ページを 1 枚に」は A4・B5・Letter の縦用紙に左上→右上→左下→右下で配置。カード下の「用紙とページ数」で選びます。各系列に3ページ＋メモも用意しています。既定のレイアウトが未設定なら、地域やプリンターの既定用紙に合わせて A判 / Letter 系を選びます。
- 印刷の設定（原文は変えず、刷るときだけ足す）: 上下左右の余白（内側・外側も）、ヘッダー・フッター、見出しごとの改ページと右ページ始まり、紙に足す目次
- ノートページ: 書き込むためのページを、見開きの左右・各ページの裏・章の終わりに入れる。大学ノート・方眼・原稿用紙・かわいい柄など 17 のひな形から選び、線の種類・太さ・間隔・色を変えて保存できる。PDF や画像にも入る
- 印刷画面で選んだプリンターへダイアログなしですぐ印刷（システムの印刷画面も選べる）と、PDF 書き出し（コンビニ印刷などに持ち出す用）
- 選んだプリンターに刷れないレイアウト（入らない用紙、両面に刷れない）には小さな札が付き、そのまま「印刷」を押すとすぐには送らずシステムの印刷画面を開きます
- 裏面の回転（長辺／短辺とじ別）と出てくる順をプリンターごとに記憶。紙 1 枚の「両面のテスト印刷」で裏面の向きを確かめて保存できます。
- 紙の外にツールバーを置く表示（**表示 › ツールバーを常に表示**、⌥⌘T。切るとポインタを乗せたときだけ紙の端に重ねて出し、窓は紙だけになる）。見開き・単ページの表示、ぼけない拡大縮小。ホイールやトラックパッドでも、選んだ送り方（フェード・スライド・めくり・重ねる・引き抜く・ワイプ・ズーム）でページを送る（感度は設定で変えられる）。Markdown などスタイルを使う文書は、単ページのスクロールでページの継ぎ目の余白を詰めて続けて読める（切り替え可）。見開きの最後のページは綴じ方向の側に寄る。ページ番号は表示用と印刷用を別々に出し入れでき、下の余白に出す（単ページの連続スクロールでは出さない）
- **ヘルプ › キーと操作**とツールバーの**… › キーと操作**で同じ一覧を開けます。Tab / M（ツールバー）、⌥⌘T（ツールバーを常に表示）、V（表示のオプション）、T（文字選択）、⌥（ドラッグの入れ替え）、端クリックとダブルクリック、ピンチと ⌘＋スクロール（拡大・縮小）、⌘F（文書の中を検索。⌘G・⇧⌘G で次・前の一致）、⌥⌘G（ページへ移動）、⌘R（再読み込み）、⌘P・⌥⌘P・⌘1〜⌘6（印刷）、Esc（戻る）を、操作が効く条件とともに案内します
- 印刷レイアウト・用紙の向き・余白・ページ番号・スタイルと文字の大きさ・HTML のノイズ除去プリセットを、名前付きの「設定セット」として保存し、別の文書に当てられる。設定画面で名前の変更・削除もできる
- 新しい文書の既定値やアプリ全体の設定は **Surimono › 設定…**（⌘,）から開く。この文書だけの操作は「表示」「文書」にある
- 変えた設定はファイル名ではなく内容（SHA-256）ごとに覚え、次に開いたときに戻す。画像の束は画像の組ごと
- ZIP の中の画像を 1 つの画像の束として開く（フォルダの奥まで集めて名前順。ディスクには展開しない）
- 窓を常に最前面に固定（**表示 › 最前面に固定**）
- 外観はシステムのライト / ダークに従う

## Finder とショートカットから

- **Finder**: ファイルを選び、サービス →「Surimono で刷る」（Finder メニュー、またはコンテキストメニューの末尾）を選ぶと、用紙を並べた印刷モードで開きます。「印刷」を押すまで、プリンターには何も送りません。1 つのファイルは文書、複数の画像は画像の束、それ以外の組み合わせは合本になります。項目が出ないときは、システム設定 → キーボード → キーボードショートカット → サービスでオンにします。
- **ショートカット**: 追加のアプリなしで、2 つのアクションを使えます。
  - 「Surimono で PDF を書き出す」は、ファイルを受け取り、用紙に並べた PDF を返します。レイアウト（A4 の冊子、2 ページを 1 枚に、など）とスタイルの名前を選べ、空のままなら Surimono の設定の既定を使います。窓を開かずに動きます。元のファイルの隣や利用者のフォルダには何も書きません。途中のファイルはアプリの一時ディレクトリに置いて消し、PDF はメモリのまま返します。
  - 「Surimono の印刷モードで開く」は、Finder のサービスと同じように、ファイルを印刷モードで開きます。前のアクションが作ったファイルはショートカットの実行中しか存在しないので、1 つならメモリから開きます。複数のファイルや ZIP は、先に「ファイルを保存」で保存してください。

| 形式 | 拡張子 |

| Markdown | `.md`, `.markdown` |
| PDF | `.pdf` |
| 画像 | `.png`, `.jpg`, `.heic`, `.gif`, `.tiff`, `.webp` など |
| Org | `.org` |
| テキスト | `.txt` などのテキストファイル |

## インストール

1. [最新のリリース](https://github.com/phyten/surimono/releases/latest)から `Surimono-<版>.dmg` をダウンロードして開き、Surimono を「Applications」へドラッグします。
2. Surimono はまだ Apple の公証を受けていないため、初回の起動は macOS に止められます。リリースノートの手順（「システム設定」→「プライバシーとセキュリティ」→「このまま開く」）で開いてください。2 回目からは普通に開けます。

アップデートはアプリの中でできます。**Surimono メニュー →「アップデートを確認…」**を選ぶか、自動で確認させます（起動のたびと、起動したままなら 1 日ごとに確認します。2 回目の起動で聞かれます。設定の「一般」でも切り替えられます）。設定の「一般」では、更新が見つかったときに「知らせる（既定）」か「自動で入れる」を選べます。「知らせる」では起動直後に Sparkle のダイアログを出し、作業中のため表示が保留されるときは、キーボードの操作を奪わない小さな「更新があります」の案内から「更新を表示…」で開けます。「自動で入れる」では裏でダウンロードし、終了時に入れ替えて次の起動から新しい版になります。以前 Sparkle で選んだ自動インストールの設定は引き継ぎます。アップデートは署名を確かめてから入れます。確認のときは GitHub から小さな一覧を取りに行くだけで、文書についての情報は送りません。

最近使ったファイルは、移動に追随するブックマークとともに Surimono 自身も保存します。更新後に macOS の一覧が空になった場合は、起動時に、なくなったファイルを除いて戻します。「メニューを消去」で両方の一覧が消えます。この版で初めて記録する前に失われた一覧は復元できません。

## ソースからのビルド

macOS 15 以降と Xcode 26 以降（Swift 6.2 以降）が必要です。Xcode を使用する開発者ディレクトリに選択してからビルドしてください。CI は Xcode 26.6、ローカル開発は Xcode 27 にも対応します。

```bash
make build                      # Debug ビルド（build/DerivedData）
make run FILE=Samples/sample.md # ビルドして文書を開く
make lint                       # Swift の整形チェック
make format                     # Swift ソースを整形
make test                       # パッケージとホストアプリ付きテスト
make test-kit                   # パッケージのテストのみ
make test-app                   # ホストアプリ付きテストのみ
make package                    # build/release に Release の DMG・ZIP と SHA-256 を出力
make clean                      # ビルド生成物を削除
```

`Surimono.xcodeproj` を開き、共有スキーム `Surimono` でもビルドできます。ビルド時は `CONFIGURATION`・`DERIVED_DATA`、パッケージ作成時は `VERSION`・`BUILD_NUMBER` を指定できます（`0.2.0-beta.1` のようなプレリリースでは `MARKETING_VERSION=0.2.0` も指定します）。署名はアドホックのため、開発者アカウントは不要です。文書変換から印刷プレビュー、印刷、PDF 書き出しまでを SurimonoKit の描画パイプラインで接続しています。

`Samples/` に Markdown・Org・UTF-8／Shift_JIS テキスト・HTML・CSV のサンプルがあります。`booklet-demo.md` は冊子の読み順を確認するための、画像を含まない長い文書で、`callouts.md` はすべての種類の囲みの見本です。設定画面で余白・ページ番号・裏面回転・HTML の JavaScript を指定できます。ユーザー CSS は `~/Library/Application Support/Surimono/Styles/`、JSON プリセットは `Presets/` に追加し、設定画面から再読み込みします。Markdown などの印刷スタイル（ユーザー CSS も）が `html` に付けた背景（紙の色や罫線）は余白まで敷かれ、模様は本文の左上にそろいます（横に大きくはみ出す文書では本文の範囲だけになります）。外部で保存した文書は自動で再読み込みし（Markdown は変わったブロックの左に薄い赤の線を出します。印刷には出ません）、元のファイルには書き込みません。

## 言語

英語・日本語・中国語（簡体字）・中国語（繁体字）・韓国語・フランス語・ドイツ語・スペイン語に対応しています。
**Surimono › 設定… › 一般 › 言語**から選び、案内に従って再起動してください。**システム（既定）** は macOS の言語設定に従います。**macOS のシステム設定 › 一般 › 言語と地域 › アプリケーション** からも変更できます。

ホスト側で表示を確認する際は、Debug アプリに `-AppleLanguages '(de)'` を指定します。`de` は `en`・`ja`・`zh-Hans`・`zh-Hant`・`ko`・`fr`・`es` に置き換えられます。既存の `-SurimonoSnapshotPath`、`-SurimonoPopover style|view`、`-SurimonoMode print|compare`、`-SurimonoMenu full` と組み合わせて使えます。言語ごとに新しいインスタンスを起動してください。メニューやテーマ名も再起動後に切り替わります。
