# LaTeX 比較コーパス

模型工房を題材にした架空の短文書116件（17分類）です。各フォルダーの main.tex が入力です。manifest.json は分類・エンジン・機能・該当する図の難度（grade）と、採取時の組版結果を記録します。分割原稿・文献・生成画像も各文書に含まれます。

対応する実 TeX の出力は ../../reference/latex/<3桁のID>.pdf にあります。参照 PDF は110件です。全116件を Surimono で描画するため、参照のない文書も回帰を検出できます。参照の更新はリポジトリのルートで `make snapshots-reference` を実行します。ローカルの TeX Live、クラス、パッケージ、フォントを使います。

083（beamer）の参照 PDF は、取り込んだアイコンのメタデータに含まれていた TeX の絶対パスをファイル名に短縮しています。ページの描画ストリームは元のままです。再生成時も pdfTeX の取り込み元パスを埋め込まない設定を使います。

108〜112 は書籍・論文集・和文標準クラスの比較です。書籍は既定の両面組で挿入される白ページも数えます。

113・114（NeurIPS）と117・118（ICLR）の参照 PDF は、原稿の隣に公式スタイルキットを置いて作成しました。キットは同梱していないため、`make snapshots-reference` はこの4件をスキップし、収録した参照 PDF を保持します。
