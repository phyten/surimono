# LaTeX 比較コーパス

模型工房を題材にした架空の短文書96件（15分類）です。各フォルダーの main.tex が入力です。manifest.json は分類・エンジン・機能・該当する図の難度（grade）と、採取時の組版結果を記録します。分割原稿・文献・生成画像も各文書に含まれます。

対応する実 TeX の出力は ../../reference/latex/<3桁のID>.pdf にあります。初回収録は90件です。全96件を Surimono で描画するため、参照のない文書も回帰を検出できます。参照の更新はリポジトリのルートで `make snapshots-reference` を実行します。ローカルの TeX Live、クラス、パッケージ、フォントを使います。

083（beamer）の参照 PDF は、取り込んだアイコンのメタデータに含まれていた TeX の絶対パスをファイル名に短縮しています。ページの描画ストリームは元のままです。再生成時も pdfTeX の取り込み元パスを埋め込まない設定を使います。
