観測の手順
----------

夕方の灯台で、*紙の色* と **光の向き** を観察した。西側の記録は
`測定表 <#readings>`_ にまとめた。

#. 青い紙を窓にかざす。
#. 白い紙と重ねて輪郭を比べる。

   - 乾いた紙を上にする。
   - 風の強い日は板で押さえる。

.. note:: 紙には鉛筆で時刻を書く。インクは乾くまでにじむ。

.. _readings:

測定表
------

=====  =====  =====
時刻   方角   紙
=====  =====  =====
17:00  西     青
18:00  南西   白
=====  =====  =====

値は 2 回の平均 [#mean]_。記録係は次の書式を使った::

    17:00   west   blue
    18:00   west   white

.. [#mean] 同じ窓で、紙の向きだけを変えて測った。
