# 星見図書室の手引き

星見図書室は、町の高台にある小さな図書室です。当番の人は、開館の前にこの手引きを一度読んでください。囲みは `:::name` でも `> [!name]` でも書けます。

## 貸し出しの決まり

貸し出しは一人五冊まで、期間は二週間です。大判の星図と貴重書は館内だけで読めます。

:::note 注意事項
返却が三週間を過ぎたら、貸出簿の連絡先へ葉書を送ります。催促の電話はしません。
:::

:::info 開館の時間
火曜日から金曜日は十時から五時まで、日曜日は三時までです。
:::

:::tip 探すときのコツ
見つからない本は、貸出簿を見る前に棚の前後を探してください。
:::

:::success 今月の照合
貸出簿の照合が終わりました。行方不明の本はありません。
:::

## 蔵書の扱い

:::important 予備の鍵
予備の鍵は責任者が持っています。自分で探し回らず、すぐに連絡してください。
:::

:::example 貸出カードの書き方
カード番号 1042、名前 月島 ほたる、返却日 11 月 18 日。
:::

## 夜の観望会

観望会は、晴れた土曜日の夜に屋上で開きます。足もと灯は赤いものだけを使います。

:::warning 足もと
階段は狭いので、上りは東、下りは西の一方通行にします。
:::

:::question 曇りの夜は
午後三時の空を見て決めます。曇りなら閲覧室で星図を広げます。
:::

:::danger 望遠鏡の重り
子どもの手が届く所に置かないでください。足の上に落ちると大けがをします。
:::

## 当番の帳面

気づいたことは日誌に書き、翌日の当番へ申し送ります。

:::bug 貸出簿の番号
十月の頁で 1037 が二度書かれています。次の当番が直します。
:::

:::quote 館長のことば
空は誰のものでもありません。順番を待つあいだに、隣の人と話してみてください。
:::

## 引用の書き方と表題のない囲み

> [!NOTE]
> 表題を書かなければ、名前が札の文字になります。

> [!caution] 別名は同じ群へ
> `caution` は `danger` と同じ形です。

:::message
Zenn の `:::message` は札を出さず、枠と地だけの箱になります。
:::

:::tip
入れ子もできます。

::::warning 内側の囲み
内側は外側の地の上に載ります。
::::
:::
