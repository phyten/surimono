# 紙を折る手順

この文書は、文章の点検を試すために書いた見本です。内容は架空の手順で、実在の人や製品とは関係がありません。

## 準備

机の上を片づけて、紙を一枚だけ置きます。紙の向きをを確かめてから、手前の辺を奥の辺に重ねます。

折り目は、定規を当てて一度だけ強くなぞります。折り目が浅いと、あとで開いたときに折り目が戻ってしまい、折り目の位置がずれます。

## 長い文の例

紙を半分に折ったあとで、さらに左右の端を中央の線に合わせて折り、開いたときに四つの区画ができていることを確かめ、区画の大きさがそろっていなければ最初の折り目からやり直すことにしておくと、仕上がりのずれを早いうちに見つけられます。

ますます手が慣れてくると、人々はいろいろな折り方を試したくなります。
