# 設定の手引き / Setup notes

この見本は、日本語と英語が混ざった文書を試すために書きました。設定の名前はどれも架空のものです。

The notes below are written in English. Each paragraph describes one made-up option.

設定ファイルは `config.toml` に置きます。サーバーを起動する前に、サーバーの名前とサーバーの番号を書いておきます。

Restart the service after every change. A change that is not followed by a restart has no effect.
