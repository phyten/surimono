# Surimono の使い方

Surimono は、Markdown・PDF・画像・Org・テキスト・CSV・HTML・LaTeX のファイルを開いて、そのまま紙に刷るための Mac アプリです。開くと紙の姿で表示され、⌘P を 2 回押せば印刷が始まります。

この案内も、ふつうの Markdown の文書です。読み終えたら、この文書を小さな冊子に刷って、折ってみてください。

## Surimono でできること

- **開いたまま刷る**: 文書は開いたときから紙のページに組まれています。表示している紙と、印刷画面に並ぶ紙は同じものです。
- **レイアウトを選ぶ**: 片面・両面のほか、中綴じの冊子、2 ページを 1 枚に並べる刷り方、3 ページ＋メモ欄などを選べます。
- **スタイルを着せ替える**: Markdown などの文字の文書は、見出しや本文の見た目（スタイル）を見本から選べます。
- **文書を変えない**: Surimono は開いたファイルに書き込みません。保存も上書きもせず、隣にファイルを作ることもありません。
- **文書ごとに覚える**: 選んだレイアウトやスタイルは、文書の内容ごとに覚えます。次に同じ文書を開くと、そのときの設定で表示されます。

## 紙を読む

開いた文書は、窓いっぱいに紙のページで表示されます。窓のツールバーから、目次・見開きと単ページの切り替え・ページの送り方を選べます。よく使うキーは次のとおりです。

| キー | すること |
| --- | --- |
| ⌘F | 文書の中を検索する |
| ⌥⌘G | ページ番号を指定して移動する |
| ダブルクリック | 拡大と、窓に合わせる大きさを切り替える |
| ⌘P | 印刷画面を開く。印刷画面では刷る |
| ⌘1〜⌘6 | レイアウトを選んで印刷画面を開く |
| Esc | 印刷画面から表示に戻る |

## 刷ってみる

印刷は 3 つの手順です。

1. ツールバーの右端にある朱色の「印刷…」を押すか、⌘P を押します。印刷画面に移り、出てくる用紙がそのまま並びます。
2. 「使う用紙」から、手元の用紙の半分の大きさの冊子を選びます。A4 の用紙なら「A5 冊子」、B5 なら「B6 冊子」、Letter なら「Half Letter 冊子」です。用紙 1 枚の表と裏に 4 ページを刷り、重ねて中央で折ると冊子になります。用紙の種類は「使う用紙」の横の「A4・A3」「B5・B4」「Letter・Tabloid」で切り替えます。
3. 朱色の「印刷」を押すか、もう一度 ⌘P を押します。選んであるプリンターへ、確認の画面を出さずに送ります。

> [!note] 印刷画面は確かめる場所です
> 印刷画面に移っただけでは、紙は出ません。用紙の並びを見て、違っていれば「表示に戻る」か Esc で戻れます。送り先は、プリンターの名前のボタンから選びます。部数や用紙トレイなどをプリンター側で決めたいときは、同じメニューの「システムの印刷画面で印刷…」を使います。

刷る前に、冊子の仕上がりを画面で確かめられます。印刷画面の「折った仕上がりを見る」を押すと、二つ折りにした冊子を読む順にめくれます。

## 冊子に折る

冊子では、1 枚の用紙に 4 ページが入ります。ページ数を $n$ とすると、用紙の枚数 $s$ は次のとおりです。

$$s = \left\lceil \frac{n}{4} \right\rceil$$

4 ページに満たない分は、最後のほうのページが白紙になります。

| 文書のページ数 | 用紙 | 白紙のページ |
| ---: | ---: | ---: |
| 8 | 2 枚 | なし |
| 10 | 3 枚 | 2 ページ |
| 16 | 4 枚 | なし |

印刷画面には、仕上がりのページ数と白紙の数、使う用紙の枚数が出ます。右から開く冊子にしたいときは、「すべての印刷設定…」の「冊子のとじ方」で「右とじ」を選びます。

刷り上がった用紙は、次の順に仕上げます。

- [ ] 出てきた用紙を、順番を変えずにそろえて重ねる
- [ ] 1 ページ目が外側に来る向きで、束ごと中央で二つ折りにする
- [ ] 真ん中の見開きを開き、折り目の上と下の 2 か所をホチキスでとめる

ホチキスは、中綴じ用の奥まで届くものがあると楽です。ふつうのホチキスなら、開いた束を厚紙の上に置いて内側から針を通し、裏で針の先を手で折り曲げます。

## スタイルを変える

Markdown・Org・テキスト・CSV・LaTeX の文書は、スタイルを選べます。

1. 印刷画面にいるときは、「表示に戻る」か Esc で表示に戻ります。
2. ツールバーのスタイルのボタン（パレットの絵と「標準」など、いまのスタイルの名前）を押すか、「文書」メニューの「見本からスタイルを選ぶ…」を選びます。「最近使った」「お気に入り」「定番」とカテゴリーから探せます。
3. 見本にポインタを乗せると、紙がそのスタイルで組み直されて試せます（印刷画面では見本が大きくなるだけです）。設定の「見本に乗せたら紙で試す」を切っているときや、組むのに時間がかかる文書では、乗せても紙は変わりません。クリックすれば、どの場合もそのスタイルに決まります。

「スタイルを見比べる」では、4 つまで並べて比べられます。文字の大きさは「表示」メニューの「文字を大きく」（⌥⌘+）と「文字を小さく」（⌥⌘−）で変えます。

この案内の囲みは、Markdown では次のように書いています。

```markdown
> [!note] 印刷画面は確かめる場所です
> 印刷画面に移っただけでは、紙は出ません。
```

## 仕上げを足す

印刷画面の下の帯で、紙の仕上げを選べます。

- 「ヘッダー・フッター」: ページ番号やファイル名を、紙の上と下に入れる
- 「改ページ」: 大きな見出しの前でページを改める
- 「目次ページ」: 見出しから紙の目次を作る
- 「ノート」: 書き込むためのノートのページを足す

余白などの細かい設定は「すべての印刷設定…」にあります。紙に刷らずに残したいときは、印刷画面の「PDF に書き出す」（⇧⌘E）で、並んでいる用紙のとおりの PDF を書き出せます。

## うまくいかないとき

### 裏面が上下逆さに出る

印刷画面のプリンターの名前のボタンから「両面のテスト印刷…」を選ぶと、表と裏に矢印のある用紙が 1 枚出ます。画面の案内どおりに用紙をめくって裏の矢印の向きを確かめ、「上（表と同じ）」か「下（逆さ）」を答えます。答えはプリンターととじ方ごとに覚え、以後は裏面を回して刷ります。冊子（短辺とじ）とふつうの両面（長辺とじ）は、それぞれでテストします。

### ページの順番が逆に重なる

用紙を表向きに出すプリンターと、裏向きに出すプリンターがあります[^order]。重なった順が逆になったときは、「すべての印刷設定…」の「プリンターとの調整」で「用紙の出力順」を「最後の用紙から」か「最初の用紙から」に切り替えます。これもプリンターごとに覚えます。

### 文書の隣の画像が表示されない

文書と同じフォルダにある画像が出ず、お知らせに「フォルダへのアクセスを許可…」が出ているときは、Surimono にそのフォルダを読む許可がありません。そのボタンを押し、文書があるフォルダか、その上のフォルダを選びます。一度許可したフォルダは覚えます。

## 自分の文書を開く

ここからは、お手持ちの文書で試してください。

- 「ファイル」メニューの「開く…」（⌘O）で選ぶ
- Finder から、Dock の Surimono のアイコンか、起動したときに出る窓へドロップする
- コピーした文字を、「クリップボードから開く」（⌘N）で開く

画像をいくつか選んで一度に開くと 1 つの「画像の束」に、文書をいくつか選ぶと 1 つの「合本」になり、まとめて刷れます。設定を最初の状態に戻したいときは、「文書」メニューの「この文書の設定を戻す」を選びます。

この案内は、「ヘルプ」メニューの「Surimono の使い方」からいつでも開けます。キーの一覧は同じメニューの「キーと操作」にあります。

[^order]: 表向きに出すプリンターでは、最後の用紙から刷ると、取り出したときにページの順に重なります。
